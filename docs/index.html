QR File Drop ✓ Ready to work offline

Move a file from your computer to your phone using the camera. No internet, no cables, nothing uploaded.

How does it work?
  1. Open this same page on the computer and on the phone.
  2. On the computer, tap Send a file and choose the file. A moving square code appears.
  3. On the phone, tap Receive a file, then Start camera, and point it at the code.
  4. Hold still until the bar is full, then tap Save file.
Use it without internet (add to Home Screen)

Open this page once while online. When you see ✓ Ready to work offline at the top, it works with Wi‑Fi and data off.

iPhone (Safari): tap the Share button ⬆︎, scroll down, tap Add to Home Screen, then Add.

Android (Chrome): tap the menu ⋮, then Add to Home screen or Install app.

Mac: in Chrome, click the install icon at the right of the address bar. In Safari, choose File → Add to Dock. Or just bookmark it.

Small files work best. A 1 MB photo takes about 4 minutes. Turn your screen brightness up.

On your phone, open this page, tap Receive a file and point the camera here. Keep this code visible until the phone says it is done.

Advanced

The phone needs to see each code clearly. If it gets stuck, choose “Slower”. Changing size or error correction restarts the transfer on the phone.

Your phone will ask to use the camera. Tap Allow. Nothing leaves your phone.
